# DUPESPACE V1.2.0

V1.2.0 重新設計 Windows 桌面操作流程，讓第一次使用者只要加入想整理的資料夾，
就能看懂掃描範圍並安全開始；同時修正 Google 帳號持久登入的可觀測性。

## 更直接的本機清理

- 不再強制要求獨立保留區；每個精確重複群組自動鎖定最舊檔案。
- 可點擊大型選取區或拖入一個以上資料夾，完整遞迴掃描所有普通子資料夾。
- 可把整理位置內的子資料夾設為保護資料夾，保護項目參與比對但永遠不可選取。
- 掃描畫面持續顯示目前資料夾完整路徑、已檢查檔案數與輪替提示。
- 修正舊流程把大型保留區一起計入掃描數量，造成少量目標看似掃描上萬檔案的困惑。

## 一致的桌面體驗

- 移除工作區上方工具列與固定通知列，主內容獲得更多可用空間。
- 側邊欄可收合；Google 帳號或未登入狀態固定顯示於左下角。
- 新增應用程式內 GitHub 與問題回報頁，並提供結構化 Bug／功能建議表單。
- 維持網站的深青、薄荷綠、圓角卡片與清楚狀態層級。

## Google 登入與診斷

- Desktop OAuth 同時使用已核准的 Drive 與 `userinfo.email` 範圍。
- 登入成功後以 Windows DPAPI 原子保存權杖，重新啟動會在背景嘗試恢復連線。
- 側邊欄顯示 Google 帳號與可取得的頭像。
- 登入失敗顯示實際且去敏後的原因，並在本機保存不含 Token 的診斷事件。
