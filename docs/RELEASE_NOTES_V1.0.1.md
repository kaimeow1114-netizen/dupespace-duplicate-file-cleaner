# DUPESPACE V1.0.1

V1.0.1 是 V1 正式版的入口清晰度與介面安全修正版。

## 網站與清理流程

- 導覽列改為近滿版配置，放大主要導覽文字並減少兩側無效留白。
- 右側操作順序調整為 GitHub、立即清理、Google 帳號；中型螢幕自動將帳號縮為頭像，小型螢幕再隱藏 GitHub。
- 清理頁新增 Google Drive 與 Windows 本機資料夾雙入口，避免使用者誤以為桌面版只能清理雲端硬碟。
- Windows 本機清理由桌面版執行，以維持 Windows 資源回收筒、保留區／清理區與專案保護規則；網站不直接永久移除本機檔案。
- 移除「忽略系統暫存檔」進階選項，固定採用嚴格比對，降低一般使用者的決策負擔。

## 安全原則

- 預設處理方式維持移至垃圾桶或資源回收筒。
- 不因垃圾桶操作失敗而改用永久刪除。
- 每個重複群組至少保留一份；永久刪除不自動預選。
- Google Drive 清理頁維持無廣告，Google 使用者資料不提供給 AdSense。
