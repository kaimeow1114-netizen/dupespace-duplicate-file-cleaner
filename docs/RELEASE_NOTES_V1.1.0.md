# DUPESPACE V1.1.0

V1.1.0 讓網站下半頁的產品價值更容易被看懂，並替 Windows 桌面版加入安全的內建更新流程。

## 網站動態敘事

- 儲存健康趨勢改為會在進入視窗時繪製的資料曲線與分數回彈。
- 重複成因分析以漸進長條顯示來源比例；防護設定檔逐項顯示目前保護狀態。
- Google Drive 隱私區以資料邊界圖清楚區分「必要中繼資料」與「不傳輸的檔案內容」。
- 信任比較矩陣逐列揭示，並加入可驗證原始碼的獨立行動卡。
- FAQ 改為可鍵盤操作的動態手風琴；全數支援減少動態效果且不隱藏安全資訊。

## Windows 內建更新

- 應用程式啟動後每天最多背景檢查一次公開 GitHub Release。
- 側邊欄可手動檢查，發現新版時直接在應用程式內下載。
- 嚴格限制 HTTPS、GitHub 來源、穩定語意版本、資產名稱與檔案大小。
- 先下載 `SHA256SUMS.txt`，串流下載安裝檔並核對 SHA-256；啟動安裝前再次完整複驗。
- 不靜默安裝、不在背景自動執行、不要求管理員權限；由使用者明確確認後才啟動可見安裝程式。
- 安裝期間允許正常關閉舊程式，但不自動重新啟動應用程式。

## 升級說明

v1.0.1 尚未包含更新器，因此既有使用者需要手動安裝 v1.1.0 一次。從 v1.1.0 開始，後續版本可直接在應用程式內完成下載、驗證與安裝啟動。
