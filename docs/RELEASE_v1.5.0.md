# DUPESPACE v1.5.0

## 安全與可靠性

- Windows 保護子資料夾與外層最舊原檔分別保留；保護區副本不能取代外層原檔。
- 整資料夾操作排除包含保護目錄、任何檔案 keeper、空檔 keeper 或 hard link 的情況。
- Google Drive 每個操作重新驗證 keeper；逾時、部分失敗與不完整結果會提示重新掃描，絕不從垃圾桶改為永久刪除。
- 永久刪除改用必須主動勾選的風險確認，保留大量操作倒數、取消及 Enter 防誤觸。

## 使用體驗

- 掃描完成才顯示整理評分、容量與分析卡片；數字約一秒內平滑呈現，支援減少動態效果。
- 評分按容量連續配分，少於 1 MiB 至少 95 分；2–4 GiB 由 30 平滑降至 20，不製造突兀警報。
- 容量比例計算所有群組，分母分別為已比對容量與 Google 提供的配額上限。
- 費用等值預填 100 GB／NT$65 月費參考，可修改；不代表帳單折扣或已釋放垃圾桶空間。
- 私人圖片、影片與 PDF 的 Google 小縮圖按需轉送，不保存、不下載原始檔；保留外層小縮圖及展開大預覽。
- 沒有重複檔案時顯示友善成功畫面；「整理其他資料夾」回到空白選擇頁，「調整位置」保留目前路徑。
- 完成頁可繼續整理，通知會淡入淡出並自動消失。移除紙張／掃地雜音，只保留短促柔和雙音。
- 每次清理只產生一份日期命名 CSV；中斷仍保留待處理與已確認結果，不刪除既有歷史報告。

詳細防護驗證與限制請見 [安全修正紀錄](SAFETY_FIX_v1.5.0.md)。
