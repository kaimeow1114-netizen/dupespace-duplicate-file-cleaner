# DUPESPACE v1.5.1

本次正式 Windows 安裝檔包含 [v1.5.0 的全部安全與體驗修正](RELEASE_v1.5.0.md)。

v1.5.0 安裝檔未通過最後整合測試，因此沒有發布下載。本版補正兩個測試假設：

- 檔案時間相同時，測試必須修改實際 keeper，而非假定特定檔名必定最舊。
- 真實回收筒測試同時建立保護子資料夾原檔與獨立的外層原檔，處理另外兩個副本後確認兩者均保留。

不變更既有垃圾桶預設、獨立永久刪除、保護目錄限制或 Google OAuth scope。
網站已部署本次相同的 v1.5 清理體驗；網站版本與 Windows 安裝檔版本可獨立發布。
