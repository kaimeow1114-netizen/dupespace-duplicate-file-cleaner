# DUPESPACE v1.4.0

- 網頁新增「未展開群組」小縮圖；保留既有的大預覽與完整路徑，兩者並存。
- 網頁處理模式標籤移至標題旁，放大字級及說明。
- 桌面群組改為左側保留檔、右側副本，初始顯示三份，之後每次再顯示二十份。
- 精簡桌面工具列，窄視窗使用詳情抽屜，保留明確且互不重疊的勾選與預覽區。
- 滾輪採適中像素距離與平滑過渡；減少動態模式不使用滾動動畫。
- 常用位置改為明亮品牌底色；大型掃描標題每六秒輪播。
- 本機影片及額外圖片格式採 Windows 縮圖提供者，使用有限時的背景子程序。
- Drive 縮圖直接從 Google 提供的縮圖網址載入，不新增代理伺服器或 OAuth 權限。

## 安全與限制

預設垃圾桶、保留檔與專案保護、執行前驗證、CSV、永久刪除獨立確認均維持。
不支援、不可取得或逾時的縮圖保留類型圖示；不下載影片原檔來播放預覽。
Windows 本機縮圖可用性取決於系統已安裝的縮圖提供者與格式支援。
測試使用合成資料，未掃描或清理使用者的真實檔案。
